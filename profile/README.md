# Halo Semua...

Ini adalah Akun GitHub resmi KCT. Informasi tentang perusahaan dan layanan kami ada di [kct.co.id](https://kct.co.id).

## Proyek

- [mockoon-ui](https://github.com/KCTOfficial/mockoon-ui): UI web untuk mengelola environment mock API Mockoon. Dibuat dengan React 19, Vite, Hono, dan Tailwind CSS.
- [grocery-restable](https://github.com/KCTOfficial/grocery-restable): mengubah database MySQL/MariaDB, PostgreSQL, atau SQLite menjadi REST API. Query bergaya PostgREST, konfigurasi bergaya Grocery CRUD, dan dikelola lewat GUI seperti phpMyAdmin.

## Kontribusi

Issue dan pull request bisa diajukan langsung di repositori terkait. Untuk melaporkan masalah keamanan, gunakan *Report a vulnerability* di tab Security repositori tersebut, jangan lewat issue publik.
