## 👋 Tentang Kami

Selamat datang di akun GitHub resmi **KCT**. Informasi lengkap mengenai layanan dan perusahaan kami tersedia di **[kct.co.id](https://kct.co.id)**.

## 🤝 Berkontribusi

Kami menyambut kontribusi dari komunitas. Sebelum mengirim pull request:

1. Baca `README` dan panduan kontribusi di masing-masing repositori.
2. Buka *issue* terlebih dahulu untuk perubahan besar agar dapat didiskusikan.
3. Pastikan kode lulus pengujian dan mengikuti gaya penulisan yang berlaku.

## 🔐 Keamanan

Jika Anda menemukan celah keamanan, **mohon jangan membukanya sebagai issue publik**. Laporkan secara privat melalui fitur [Security Advisories](https://docs.github.com/en/code-security/security-advisories) di repositori terkait atau hubungi kami melalui [kct.co.id](https://kct.co.id).
